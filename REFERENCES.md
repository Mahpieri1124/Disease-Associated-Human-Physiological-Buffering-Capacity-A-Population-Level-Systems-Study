## Reference-Use Rule

The presence of a reference in this file does not mean that the source validates the Human Physiological Buffering Capacity construct.

References are classified implicitly by their role:

```text
Direct evidence
Mechanistic background
Sri Lanka-specific context
Methodological background
Higher-order conceptual bridge
```

Future versions should expand the reference database through systematic database searches, citation chaining, grey-literature retrieval, and explicit inclusion/exclusion criteria.
